# WifiPulse 📶

A fast, cross-platform, multi-threaded Wi-Fi Network & Router Inspector written in Python.

## 🚀 Features
- **Auto Network Detection**: Automatically scans the connected local IP, Subnet, and Gateway.
- **Router Port Scanner**: Scans open ports (HTTP, HTTPS, SSH, FTP, etc.) on the connected router.
- **Active Host Discovery**: Uses multi-threading for quick active IP discovery.
- **Cross-Platform**: Operates seamlessly on macOS, Linux, Windows, and Termux (Android).

## 🛠️ Usage

### macOS / Linux / Windows
